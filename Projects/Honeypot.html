Synopsis

The goal of this project is to setup a honeypot using tpot to observe attack behaviour from real world traffic and to learn cloud operations.

The Hive – Google Cloud

1. Initial Setup

Once you have created a project you must use the side menu to access Compute Engine -> VM Instances. (This may not be immediately available, if this is you first time on google cloud you will need to enable the compute engine API.):

2. Machine Creation

Once you reach the VM instances menu click Create Instance. The required specification with minimal cost would require the following settings:

Machine Configuration:

  • Region: Any
  • Machine Type: E2
  • Preset: Standard -> e2-standard-4

OS and Storage:

  • OS: Debian 13 Trixie
  • Size: 250gbs

Networking:

  • Allow HTTP Traffic: True
  • Allow HTTPS Traffic: True
  • Network Tags (add a network tag for firewall settings): TPOT-NETWORK

You can now press create

3. Firewall Setup

Once again enter the side menu where we previously found the compute engine and choose VPC Networks -> Firewall.

After that click on Create new firewall rule:

  • Select any name
  • On specified targets -> tags options: TPOT-NETWORK
  • Source IP ranges : 0.0.0.0/0
  • Protocol and ports: Allow All
  • Save

4. T-POT Setup

SSH into the machine:

  • Install git and curl on the machine:
    • > sudo apt install git curl
  • Install T-POT
    • > git clone https://github.com/telekom-security/tpotce.git
    • Run through the installation and choose the hive option when prompted and select you username and password which will be used to access the GUI later on.
    • After the installation is done:
      • > Sudo Reboot
    • New Ports:
      • SSH: 64295
      • GUI (to view on browser): 64297
  • If running the installer fails:
    • sudo systemctl disable –now exim4
